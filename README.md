# Aisjam's Blender Tools

Welcome to my collection of Blender scripts, add-ons, and experiments.

I use Blender for 3D modelling, animation, visualisation, and procedural workflows. Over time, I've developed various tools to simplify repetitive tasks, experiment with new techniques, and improve my creative workflow.

This repository is where I share those tools with anyone who might find them useful.

## YouTube

I also create videos covering 3D modelling, Blender, creative software, and projects I'm working on.

- [Aisjam 3D — Blender and 3D content](https://www.youtube.com/@aisjam3D)
- [Aisjam — Main channel](https://www.youtube.com/@Aisjam)

Where possible, I'll include demonstrations or tutorials showing how the tools work.

## Using the Tools

Some projects are complete Blender add-ons, while others are standalone Python scripts, node setups, or experimental files.

Each project will have its own instructions where needed.

Please check compatibility with your version of Blender before using any scripts or add-ons.
